ABOUT

The Citadel is a Linux security and infrastructure lab built to document hands-on work in system administration, Docker deployment, SSH hardening, Cloudflare tunneling, authentication monitoring, and security operations.

This site is both a professional portfolio and a working operations deck. The goal is to build practical experience, document real troubleshooting, and create a clear record of technical growth toward cybersecurity, systems administration, and cloud infrastructure roles.
