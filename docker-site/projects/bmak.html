01 //

Purpose

B-MAK was designed to explore how personal operations can be organized with the same discipline used in technical systems: clear dashboards, repeatable workflows, and private source-of-truth records.

02 //

Privacy Model

The live system is private. Public portfolio material uses synthetic examples only. Personal names, real obligations, real account details, medical data, school information, and document links are excluded.

03 //

ODIN Role

ODIN is the planned watchdog layer: reminders, alerts, document checks, weekly reviews, and automation triggers that help keep the household operating smoothly.

04 //

System Areas

  • Calendar and event awareness
  • Recurring obligation tracking
  • Family vault structure
  • Private document organization
  • Future automation hooks
05 //

Security Decisions

  • Do not expose the real dashboard publicly
  • Use sanitized case-study data only
  • Keep sensitive files outside public web paths
  • Separate portfolio visuals from private operations
06 //

Roadmap

  • Private dashboard MVP
  • Calendar integration
  • Document checklist automation
  • ODIN weekly household briefings
  • Alerting through private channels

Security Note

This page is intentionally sanitized. B-MAK belongs to the private side of the Citadel ecosystem. The purpose of this public page is to demonstrate systems thinking, dashboard architecture, privacy-aware design, and automation planning without exposing real household data.
